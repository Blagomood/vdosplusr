# vDosPlusR

vDosPlusR — бесплатный и открытый проект, переработанная 64-битная версия неигрового DOS-эмулятора [vDosPlus](https://sourceforge.net/projects/vdosplus/) с полной поддержкой кириллицы. 

## Что улучшено

- **Ликвидированы кракозябры в названиях папок и файлов** — корректная
  работа с кириллицей в файловой системе.
- **Исправлен сбой при совпадении начала названий папок**.
- **Работает вставка по Ctrl-V и правой кнопкой мыши** — как в обычных
  консольных приложениях Windows.

Последний пункт можно отключить: RCLKPASTE = OFF в config.txt.  Для Borland Pascal всегда отключено независимо от этой настройки, там у ПКМ другая функция.

## Установка

1. скачайте архив со страницы [Releases](https://github.com/Blagomood/vdosplusr/releases/latest), распакуйте, запустите `vDosPlusR.exe`; вы увидите загруженный DOS Navigator.
либо 
2. возьмите отдельно vDosPlusR.exe, добавьте в вашу папку с уже настроенной vDosPlus и запускайте его.

Об ошибках и идеях по улучшению пишите в [Issues](https://github.com/Blagomood/vdosplusr/issues).
